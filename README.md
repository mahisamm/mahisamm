## What I bring to a product

- **AI systems** &mdash; vision extraction, retrieval, embeddings, schema-validated model output, provider fallbacks, and stub modes so the app boots without API keys.
- **Backend engineering** &mdash; FastAPI and Node services, Postgres schema design, migrations, background jobs, and row-level security by default.
- **Product front ends** &mdash; React and TypeScript interfaces, dashboards and charts built around one clear user loop.
- **Automation and delivery** &mdash; GitHub Actions pipelines, scheduled agents, notification hooks, Docker environments, and verification scripts that fail loudly.
- **Engineering honesty** &mdash; documented scope, explicit trade-offs, and a clear line between what is production-ready and what is a demo.

## How I work

I like problems where the interesting part is the constraint: a model whose output has to be trusted, a pipeline that has to run at 3am, a plan that must never be generated for someone who should be seeing a doctor instead. I start from the user loop, keep the deterministic core deterministic, and let the model do only the part it is genuinely better at.
